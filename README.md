# Staying Human in the Age of AI

Slides for a 45-minute talk at **Ignition 2026** for students in grades 7–12 on how to stay human in the age of AI.

## Running it

Open `index.html` in a browser. It's a single, self-contained file.

| Key | Action |
| --- | --- |
| → / Space / click | Next build |
| ← | Previous build |
| N | Toggle speaker notes |
| G | Go to slide number |
| F | Fullscreen |

The image and video placeholders are clickable upload slots. Images are saved in your browser's local storage, not in the repo. Videos need to be re-added each session.
